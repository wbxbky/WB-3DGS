# License selection before public release

No software license is asserted by this scaffold because the code may be owned
or jointly owned by the authors' institution and may incorporate third-party
components under their own licenses.

Before making the repository public, confirm the permitted license with the
corresponding author/institution and add a standard `LICENSE` file (for example,
BSD-3-Clause, Apache-2.0, or MIT only if institutionally approved). Keep all
third-party licenses/notices required by their upstream projects.

Do not publish the repository with an invented ownership statement.
